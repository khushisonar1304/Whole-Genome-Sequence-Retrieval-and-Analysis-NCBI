# Whole Genome Sequence Retrieval from NCBI

## Aim
To retrieve the whole genome sequence of a selected organism from the NCBI database and determine its genome size and accession number.

## Objective
- To explore the NCBI Nucleotide database.
- To retrieve complete genome sequence records.
- To identify the accession number of the selected genome.
- To determine the total genome size in base pairs (bp).

## Tools and Database Used
- **NCBI Nucleotide Database:** For genome sequence retrieval.
- **FASTA Format:** For accessing nucleotide sequences.

## Procedure
1. Open the [NCBI Nucleotide Database](https://www.ncbi.nlm.nih.gov/nuccore/).
2. Enter the name of the selected organism in the search bar.
3. Search for the complete genome sequence.
4. Open the appropriate complete genome record.
5. Note the accession number provided in the sequence record.
6. Identify the total nucleotide length (genome size) mentioned in the record.
7. Download the genome sequence in FASTA format if required.

## Conclusion
The whole genome sequence of the selected organism was successfully retrieved from the NCBI database. Its accession number and genome size were identified.
